# 강의 서랍 — 전체 로컬 실행 설계

상태: 사용자 요청에 따른 변경 설계. 구현 전 검토용.
위치: `/Users/luca/Documents/GitHub/lecture-inbox`

## 확정된 방향

React 화면, FastAPI, 학교 로그인·강의 다운로드, Whisper 전사를 모두 각 사용자의 컴퓨터에서 실행한다. DB를 사용하지 않는다. OCI·Vercel 배포와 중앙 서버 파일 업로드 계획을 대체한다. 학교 조회·다운로드와 최초 모델 설치에는 인터넷이 필요하다. 준비된 모델로 내 파일을 전사하는 과정은 로컬에서 수행한다.

기존 `client/`, `server/`, `scripts/` 모노레포를 유지한다. 루트에서 `npm run dev`로 화면과 API를 함께 실행하고 브라우저로 사용한다. 두 서버는 `127.0.0.1`에만 바인딩한다. 첫 구현·검증 대상은 현재 개발 환경인 macOS이며, Apple Silicon에서는 whisper.cpp의 Metal 지원을 사용한다. 다른 운영체제·GPU 지원은 실제 확인 전 보장하지 않는다.

## 접근 방식

1. 로컬 웹 화면 + Python API + whisper.cpp: 기존 코드를 재사용하고 네이티브 GPU와 파일 처리를 연결할 수 있다. 실행 환경·모델의 최초 설치가 필요하다. 선택한 방식이다.
2. 브라우저 내 전사: 설치 부담을 줄이지만 모델·메모리·파일 디코딩·WebGPU 호환성을 별도로 검증해야 한다. 현재 선택하지 않는다.
3. 데스크톱 앱 패키징: 설치·실행 UX를 개선할 수 있지만 패키징·업데이트 체계가 추가된다. 초기 범위에서 제외한다.

## 사용 흐름

### 학교 강의

학교 로그인 → 수강 과목·강의 목록 조회 → 강의 선택 → 로컬 영상 저장 → 선택적으로 전사 → 결과 열기·저장.

목록 연동은 원본 레포의 구현을 다시 확인하여 추가하고, 기존 강의 URL 직접 입력은 보조 경로로 유지한다. 실제 계정으로 확인되지 않은 목록 파싱과 접근 권한은 구현 완료나 검증 완료로 표시하지 않는다.

### 내 영상·음성 파일

학교 로그인 없이 파일 선택 → localhost API로 파일을 스트리밍 전달 → ffmpeg로 전사용 음성 변환 → whisper.cpp 실행 → 결과 확인.

브라우저의 파일 선택은 원본의 임의 경로 접근 권한을 API에 주지 않는다. 처음에는 선택한 파일을 로컬 작업 폴더로 복사하는 방식으로 구현하고 대용량 파일 전체를 메모리에 올리지 않는다. 외부 서버로 업로드하지 않는다. 사용자가 선택한 원본은 수정·삭제하지 않는다.

## 파일과 작업 상태

- 기본 파일 루트: 프로젝트의 `data/`. 화면에서 실제 저장 경로를 보여준다.
- `data/inbox/`: 로컬로 수신한 파일 및 준비된 다운로드 입력.
- `data/archive/<작업ID>/`: 처리가 성공한 원본 영상·음성 보관.
- `data/Transcripts/<작업ID>/`: TXT, Markdown, SRT, JSON 결과. 원본 이름은 정제하여 결과 파일명에 사용한다.
- `data/tmp/<작업ID>/`: 부분 다운로드·변환 음성 등 재생성 가능한 임시 파일.
- 사용자 파일명은 표시·파일명 용도로만 쓰고, 작업 경로는 서버가 만든 식별자로 구분해 충돌과 경로 이탈을 막는다.
- 원본 보관 파일과 완성된 전사본은 로그아웃·프로그램 종료·재시작으로 삭제하지 않는다. 서버 임시 파일의 30분 만료 정책을 완성 결과에 적용하지 않는다.
- 진행 상태와 대기열은 메모리에만 둔다. 재시작하면 작업 진행은 복구하지 않지만 저장된 결과는 남는다. 재시도와 기존 결과 파일 사용은 가능하다.
- 실패·취소 시 부분 결과와 변환 임시 파일을 정리한다. 전사 실패만으로 이미 내려받은 원본을 삭제하지 않는다. 작업 목록 정리와 저장 파일 삭제를 구분한다.

## 학교 인증과 로컬 작업의 수명

학교 인증과 로컬 작업 접근을 분리한다. 서비스 회원가입·계정 DB는 없다. 학교 비밀번호는 로그인 요청 중에만 사용하고 저장하지 않는다. 학교 쿠키는 해당 로컬 프로세스의 메모리에서만 유지한다.

| 사건 | 학교 접근 | 진행 중인 로컬 작업·완성 결과 |
| --- | --- | --- |
| 학교 요청에서 인증 만료 확인 | 쿠키 폐기, 재로그인 안내 | 이미 확보한 입력의 전사는 계속, 결과 유지 |
| 사용자가 학교 로그아웃 | 즉시 학교 접근 차단, 쿠키 폐기 | 전사는 계속, 원본·결과 유지 |
| 학교 접근이 필요한 작업 중 만료 | 해당 요청 실패, 명시적 재시도 | 확보되지 않은 영상은 전사 시작하지 않음 |
| 사용자가 작업 취소 | 해당 작업의 네트워크·하위 프로세스 중단 | 원본 보존, 부분 결과 정리 |
| 프로그램 종료·재시작 | 재로그인 필요 | 진행은 중단, 완성 파일은 보존 |

학교 만료는 쿠키 날짜뿐 아니라 실제 로그인 리디렉션·인증 응답으로 판단한다. 통신 장애·권한 부족을 무조건 세션 만료로 취급하지 않는다. 만료 확인을 위해 학교에 주기적으로 요청하여 세션을 연장하지 않는다. 학교 요청 시 판정하고 화면에는 로그인 필요 상태를 전달한다.

학교 로그아웃은 진행 중인 학교 요청의 늦은 응답이 쿠키나 로그인 상태를 되살리지 못하도록 처리한다. 학교 서버 세션의 명시적 로그아웃은 실제 로그아웃 URL·토큰 규칙을 확인한 경우에만 호출한다. 원격 로그아웃의 성공 여부와 무관하게 로컬 학교 접근은 차단하며, 확인 전 학교 서버 세션까지 폐기됐다고 표시하지 않는다.

## 전사 실행

whisper.cpp를 별도 프로세스로 호출하고 ffmpeg로 필요한 음성 형식을 준비한다. 기존 설치를 우선 탐지한다. 실행 파일·모델 파일 경로는 사용자 환경 설정으로 지정할 수 있게 한다. 최초 기본 모델은 한국어를 지원하는 다국어 `small`로 제안하며, 속도·품질은 샘플 전사로 확인한다. `.en` 전용 모델은 한국어 기본값으로 사용하지 않는다.

전사는 한 번에 1개만 실행한다. 대기열·입력 용량·길이·디스크 여유를 제한하고, 대기·음성 변환·전사·완료·실패·취소 상태를 구분한다. 실제 측정 없이 완료 시각이나 전사 품질을 보장하지 않는다. 모델 다운로드는 명시적인 설치 단계이며 요청할 때마다 자동으로 대용량 모델을 받지 않는다.

요약·화자 분리·외부 AI API는 이번 범위에서 제외한다.

## 로컬 보안

- localhost 바인딩에 더해 허용 Host·Origin 검사, 로컬 서비스 세션 검증, 상태 변경 요청의 CSRF 방어를 적용한다. 다른 웹사이트가 열린 로컬 API를 조작하는 경로를 차단한다.
- 로컬 서비스 세션은 학교 인증과 별개다. 학교 로그아웃이 로컬 파일 전사 권한을 없애지 않는다. 외부 네트워크에 API 포트를 공개하지 않는다.
- 명령은 인자 배열로 실행하고 셸 문자열에 사용자 입력을 삽입하지 않는다.
- 업로드는 별도 용량 제한과 실제 수신 바이트 수 검사로 처리한다. 기존 공통 8KB 요청 제한은 작은 JSON 요청용으로 유지하고 파일 전송 경로와 분리한다.
- 입력 확장자만 신뢰하지 않고 미디어 검사·처리 시간 제한·디스크 제한을 적용한다.
- 학교 HTTPS 인증서 검증을 유지한다. 영상 다운로드의 최초 URL뿐 아니라 리디렉션·HLS 하위 요청도 허용 학교/CDN 범위 밖이나 사설·로컬 주소로 이동하지 않도록 검사하는 경로를 설계·검증한다. 현재 ffmpeg 최초 URL 검사만으로 방어 완료라 하지 않는다.
- 비밀번호, 학교 쿠키, 서명된 영상 URL을 로그·오류 응답에 노출하지 않는다.

## 변경 범위와 구현 순서

1. `server/app.py`, `server/school.py`: 로컬 서비스와 학교 인증 분리, 학교 만료·로그아웃, 결과 보존 및 작업 취소 규칙 수정.
2. 학교 과목·강의 목록 조회와 다운로드 요청 경계 검증 추가. 원본 레포와 실제 응답을 근거로 구현.
3. 로컬 파일 수신·미디어 변환·Whisper 전사 및 결과 출력 추가. 관련 로직은 기존 API와 구분되는 작은 모듈로 분리.
4. `client/`: 학교 강의 / 내 파일 입력, 로그인 만료 표시, 작업 상태·취소·결과 보기·다운로드 화면 연결.
5. `scripts/`, 의존성, README: 로컬 설치·모델 준비·실행 안내 수정. OCI/Vercel 전용 설정과 배포 문서 제거. 기존 사용자 파일은 삭제하지 않음.

## 완료 조건

- 루트에서 통합 실행하고 종료하면 두 서버와 하위 작업이 정상 정리된다.
- 학교 로그인 없이 내 파일을 전사할 수 있다.
- 학교 만료 시 재로그인을 요구하되 진행 중인 로컬 전사와 완성 파일을 보존한다.
- 로그아웃 후 늦게 도착한 학교 응답이 인증을 복원하지 않는다.
- 취소·실패·재시작에도 사용자가 선택한 원본 및 완성 결과가 보존된다.
- 다른 Origin/Host, 경로 이탈, 과대 파일, 잘못된 미디어, 금지된 네트워크 목적지를 차단하는 테스트가 통과한다.
- 짧은 로컬 샘플로 실제 Whisper를 실행해 결과 파일과 GPU 사용 로그를 확인한다. 모의 전사 테스트만으로 GPU 전사를 검증했다고 하지 않는다.
- 실제 학교 계정 연동과 브라우저 동작은 별도 검증한다. 접근 수단이 없으면 한계를 명시한다.
