현재 결과물에서 확인한 문제

  • 바리스타 2주차 노트 260줄에는 표·인용·문제가 이미 존재합니다. 단순히 “내용에 표가 없다”는 진단은 틀립니다.
  • 핵심 암기사항은 172행부터 시작합니다. 강조된 추출 기준보다 발전사가 먼저 나오고, 비슷한 내용을 본문·암기·문제에서 반복합니다.
  • Study.jsx의 pre와 max-height: 360px 때문에 Markdown 제목·표·이미지가 원문 기호로 보이고 본문 안에 스크롤이 생깁니다.
  • 정답과 해설이 질문 바로 아래 노출됩니다. 매 줄 앞에 있는 시각은 읽기 흐름을 자주 끊습니다.

공개 사례 → 이 서비스의 결정

  • Cornell Note-taking System은 질문 단서와 본문을 나누고, 본문을 가린 채 답한 뒤 복습하게 합니다. 이 시안은 고정 2열 필기지를 그대로 복제하지 않고 질문·답 분리와 회상 흐름을 적용했습니다.
  • MIT 18.01 시험 자료는 복습 요약, 연습문제, 해설을 구분합니다. 실제 Exam 1 Review는 공식과 풀이 예시를 함께 제공합니다. 개념을 한 줄 정의로만 압축하지 않는 근거로 삼았습니다.
  • OpenStax Biology 2e 요약은 주제별로 나누고 원래 본문으로 연결합니다. 핵심 요약에서 개념으로 이동하는 구조를 참고했습니다. 해당 교재 문장이나 이미지를 시안에 복제하지 않았습니다.
  • The Learning Scientists의 회상 연습 안내는 보지 않고 떠올린 다음 원자료와 대조할 것을 권합니다. 정답을 숨기고 근거·개념으로 돌아가는 동선을 채택했습니다.

자료 구조와 학습 행동을 참고한 설계 판단입니다. 이 UI 자체의 학습 효과를 검증한 것은 아닙니다.

새 노트의 작성 규칙

  1. 첫 화면: 주제·자료 범위와 핵심 3–5개. 중요도는 교수의 명시적 강조가 있을 때만 표시합니다. 근거가 없으면 일반 핵심 개념으로 표현합니다.
  2. 개념 본문: 의미 → 이유·관계 → 자료에 있는 예시 → 혼동하기 쉬운 구분. 모든 항목을 기계적으로 채우지 않습니다. 비교는 표, 절차는 단계, 수식은 기호·조건·풀이를 붙입니다.
  3. 중복: 요약은 압축하고 본문을 가리킵니다. 본문의 긴 문단을 암기·문제 영역에 그대로 복제하지 않습니다.
  4. 출처: 각 개념 단위에 교안 이름·쪽과 실제 전사 시각을 연결합니다. 시간 범위는 ‘약’으로 표시하고 재생 기능이 없으면 재생 버튼으로 보이게 만들지 않습니다.
  5. 교안 이미지: 도식·수식처럼 의미를 전달하는 이미지는 본문에 캡션과 함께 표시합니다. 표를 읽기 좋게 다시 만든 경우 원본은 옆에서 펼쳐 대조합니다.
  6. 연습: 개념 회상·비교·적용 질문 3–5개부터 시작합니다. 자료로 해설할 수 있는 질문만 만들고 답과 해설을 분리합니다. 자동 채점이나 출제 확률은 만들지 않습니다.
  7. 불확실성: 학습 판단을 바꾸는 충돌은 해당 주장 곁에 표시하고, 나머지 교정 기록은 끝에서 펼쳐 봅니다. 전사 없는 내용·페이지·시각을 생성하지 않습니다.

구현할 때의 범위와 순서

  1. 기존 노트부터 읽기 개선: 별도 읽기 화면을 만들고 Markdown 제목·목록·표·인용을 안전하게 렌더링합니다. 본문 17px, 줄간격 약 1.8, 최대 폭 800px, 작은 내부 스크롤 제거. 기존 자료를 다시 생성하지 않아도 적용되어야 합니다.
  2. 교안 연결: 현재 API는 노트 텍스트만 반환합니다. 같은 과목의 허용된 페이지 이미지만 제공하는 엔드포인트와 안전한 상대경로 변환이 필요합니다. 원시 HTML·이벤트·위험한 URL은 실행하지 않으며, 모델이 임의 경로를 읽게 하지 않습니다.
  3. 노트 지침: 정리-지침.md의 시간순 불릿 중심 예시와 StudyRunner._prompt를 같은 구조로 맞춥니다. 최종 파일은 Markdown을 유지하고 새로운 DB·편집기·임의 JSON 저장 형식을 추가하지 않습니다.
  4. 신규 노트의 복습 모드: 정해진 제목과 문제·정답 경계를 활용합니다. 구형 노트에서 구획을 확실히 인식하지 못하면 전체 읽기를 제공합니다. 없는 요약·문제를 있는 것처럼 만들지 않습니다.
  5. 보존: 기존 노트 덮어쓰기 금지와 Claude·Gemini·Codex 선택을 유지합니다. 재작성은 별도 버전과 명시적 사용자 요청이 있을 때만 진행합니다.
